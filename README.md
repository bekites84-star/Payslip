# Pilot Payslip Calculator

Monthly payslip calculator for flight crew: flight, DHD, SBH and SBA hours (HH:MM), overtime above 80 hours, USD flight allowance, Ethiopian income tax and fixed deductions. Day and night themes.

Open https://bekites84-star.github.io/Payslip/ in Safari and use **Share → Add to Home Screen** to install it. It works offline after the first visit. Your figures are saved on the device only.
